# JobTrack

就職活動中の企業、選考状況、面接などの予定、ES内容をまとめて管理するWebアプリです。

## 公開アプリ

[https://jobtrack-lilac.vercel.app/](https://jobtrack-lilac.vercel.app/)

アカウント登録やインストールは不要です。データは利用中のブラウザのLocal Storageに保存されます。同じブラウザでは再度開いた後も利用できますが、別のブラウザや端末とは共有されません。

## 主な機能

- 企業名、マイページURL、ログインIDを登録
- 企業ごとに複数の選考情報を追加
- 本選考・早期選考・インターンの区分、職種、選考状況を管理
- 応募締切、面接・インターンなどの日程とメモを登録
- 設問ごとに複数のES内容を記録
- 企業名で登録企業を検索
- 選考区分や選考状況で企業を絞り込み
- ホーム画面で直近の予定を確認し、予定を選択して詳細を表示
- 登録企業や予定などの登録情報について、AIに質問
- PCとスマートフォンに対応

## 使い方

1. ホーム画面で企業名を登録します。必要に応じてマイページURLとログインIDも入力できます。
2. 登録企業一覧から企業を開き、選考情報を追加します。
3. 選考区分、職種、選考状況、日程、ES内容などを必要に応じて記録します。
4. ホーム画面の直近の予定や、登録企業一覧の検索・絞り込みで情報を確認します。
5. AIに質問する画面では、登録済みの企業情報やES内容について質問できます。

## AIについて

AIへの質問はブラウザ内で実行します。初回利用時にQwen3 0.6Bの量子化モデルデータ（約1GB）をダウンロードします。WebGPUに対応したブラウザとPCが必要です。モデルデータ取得後、質問や企業情報はAIサーバーへ送信されません。

## 使用技術

- Next.js 16（App Router）
- React 19
- TypeScript
- Tailwind CSS 4
- Local Storage
- Transformers.js（ブラウザ内AI）

## ローカルでの起動

Node.js 20.9以上が必要です。

```bash
npm install
npm run dev
```

ブラウザで[http://localhost:3000](http://localhost:3000)を開きます。

本番ビルドを確認する場合は、次を実行します。

```bash
npm run build
npm run start
```

## データについて

保存先はブラウザごとのLocal Storageです。ブラウザのデータを削除すると、登録内容も削除されます。現状、ユーザーアカウントやクラウドデータベースはありません。
